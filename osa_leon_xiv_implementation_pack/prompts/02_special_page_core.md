# Stage 02 — Build the dedicated special page

Read source docs and inspect the current special shell.

## Goal

Create the main editorial experience in `leon-xiv-argentina.html`.

## Required sections

1. Event hero
2. Short orientation / what the visit is
3. `La visita en cuatro días`
4. Agenda section mount/container
5. `Quiero participar`
6. `Recorrido`
7. `León XIV y la familia agustiniana`
8. Official sources / last update
9. Maximum 3 related OSA news items
10. Existing OSA footer

## Requirements

- same OSA header/footer;
- same palette/fonts;
- strong editorial hierarchy;
- no dashboard aesthetic;
- use semantic section headings;
- add anchor navigation where useful;
- provide a static readable baseline even before JS enhancements.

## Do not

- fabricate public access rules;
- add a CMS;
- add forms;
- add a map SDK;
- add long biography copy.

## Acceptance criteria

- page reads coherently top-to-bottom;
- visual identity feels native to OSA;
- key dates are visible above the fold on common desktop/mobile;
- no empty placeholder blocks;
- no console errors;
- links and anchors work.
