# Stage 07 — Visual polish and performance

Read the visual direction again before changing anything.

## Goal

Raise perceived quality without changing product scope.

## Polish

- hero hierarchy;
- editorial typography;
- section rhythm;
- gold rules/markers;
- button states;
- modal entrance/exit;
- timeline details;
- restrained microinteractions;
- image cropping if approved asset is used.

## Performance

- lazy-load non-critical images;
- use appropriate dimensions;
- avoid blocking third-party additions;
- keep JS small;
- remove dead duplicated feature CSS/JS;
- ensure no new library was introduced.

## Inspect specifically

The result must NOT resemble:
- SaaS landing page;
- card wall;
- Argentine flag campaign;
- Vatican-yellow clone;
- recolored Novena modal.

## Acceptance criteria

- hierarchy is clear at first glance;
- visual language remains OSA;
- no gratuitous animation;
- no layout shift caused by new media;
- no obvious performance regression;
- no dead placeholder UI.
